# Banchtop_NMR_STL_files
STL files for the NMRduino case, enclosure of the interface box and the sample holder including the coil forms.

- NMRduino case (adjusted) is based on Michael C.D. Tayler and Sven Bodenstedt. NMRduino: A modular, open-source, low-field magnetic resonance platform. Journal of Magnetic Resonance,362:107647, 2024.
- 9V battery holder is based on Kandor. 9V Battery Holder, 2022. \url{https://www.printables.com/model/221300-9v-battery-holder}. Accessed: 17 August 2026.
